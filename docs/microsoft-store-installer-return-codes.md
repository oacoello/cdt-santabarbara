# Microsoft Store installer return codes

Use these values in Partner Center for the CDT Santa Barbara EXE installer.

| Scenario | Return code |
|---|---:|
| Installation successful | `0` |
| Installation cancelled by user | `1223` |
| Application already exists | `183` |
| Installation already in progress | `1618` |
| Disk space is full | `112` |
| Reboot required | `3010` |
| Network failure | `53` |
| Package rejected during installation | `1625` |
| Miscellaneous install failure | `1` |

Documentation URLs:

- System error codes 0-499: `https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--0-499-`
- Windows Installer error codes: `https://learn.microsoft.com/en-us/windows/win32/msi/error-codes`

Notes:

- The installer is generated by Electron Builder using NSIS.
- `scripts/installer.nsh` customizes the installer to return:
  - `1223` when the user cancels installation.
  - `1618` when another installer instance is already running.
- Some Partner Center codes are declared for classification, but may be produced by Windows, policy enforcement, or installer infrastructure rather than by application code itself.
