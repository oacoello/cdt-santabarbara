# **App Name**: ARES Tactical FDC

## Core Features:

- GPS Integration: Locate gun position using device GPS.
- Targeting via Map Tap: Calculate firing solutions based on tapped location on the map.
- Observer Correction: Adjust target location based on observer input for Add/Drop and Left/Right.
- Ballistic Computation: Compute firing solutions, displaying range and QE (Quadrant Elevation).
- Simulated Firing: Simulate firing and display dispersion impacts.
- Military UTM Conversion: Convert target location to Military UTM coordinates.
- Report Generation: Generate mission reports containing coordinate, QE, and impact status, using an AI tool to classify and summarize the mission.

## Style Guidelines:

- Primary color: Tactical Green (#238636) to align with the military context.
- Background color: Dark gray (#141A21) for low-light visibility.
- Accent color: Tactical Blue (#58A6FF) to highlight interactive elements.
- Body and headline font: 'Inter' (sans-serif) for clear readability and modern look.
- Use icons from the Material Design library, colored with Tactical Green and Tactical Blue.
- Use a panel layout, dividing the screen into a map view and a control/data panel at the bottom.
- Subtle animations for firing simulations.
